> Работает офлайн, не ведет сбор данных.

> [!IMPORTANT]

## Возможности

### Анализ

| | Инструмент | Описание |
|---|---|---|
| ℹ | **Информация о файле** | Размер, тип, даты, владелец и права доступа. |
| # | **Хеширование** | SHA-256, SHA-512, MD5, BLAKE3 — контрольные суммы. |
| ☷ | **Метаданные** | EXIF, ID3, свойства PDF и Office-документов. |
| ▦ | **Hex-просмотр** | Содержимое файла в шестнадцатеричном виде. |
| ⌘ | **Определение кодировки** | Распознаёт UTF-8, UTF-16, Windows-1251 и другие. |
| ▤ | **SQLite Viewer** | Просмотр и редактирование SQLite баз данных. |
| ƒ | **Просмотр шрифтов** | Разбор TTF, OTF, TTC, WOFF: имена, метрики, глифы. |
| ⌦ | **Санитайзер EXIF** | Удаление GPS, дат, камеры и автора из фото. |

### Утилиты

| | Инструмент | Описание |
|---|---|---|
| ⇋ | **Конвертация** | Кодировка, формат, пересчёт контрольных сумм. |
| ⬡ | **Base64** | Кодирование и декодирование текста и файлов. |
| ⚿ | **Права доступа** | Просмотр и изменение прав файла (Unix/Windows). |
| ⚷ | **Генератор паролей** | Пароли, UUID, парольные фразы и hex-строки. |
| ▩ | **QR-коды** | Генерация и декодирование QR-кодов. |

### Разработка

| | Инструмент | Описание |
|---|---|---|
| .* | **Regex-тестер** | Поиск и замена по регулярным выражениям. |

### Безопасность

| | Инструмент | Описание |
|---|---|---|
| ◐ | **Стеганография** | Скрытие текста или файла в PNG (LSB). |

## Установка

### Готовая сборка

Скачайте `SemeryFiles.exe` со страницы [Releases](https://github.com/USER/SemeryFiles/releases/latest).

Требуется Windows 10 или 11. Дополнительно ничего устанавливать не нужно.

### Из исходников

```bash
git clone https://github.com/USER/SemeryFiles.git
cd SemeryFiles
pip install -r requirements.txt
python main.py ```
